# Share Server

Минималистичный сервер для обмена файлами по коротким ссылкам.

## Возможности

- Вход администратора для загрузки файлов
- Drag-and-drop, короткая ссылка, лимит скачиваний и срок хранения
- **Опциональный пароль для скачивания**
- **Ограничение доступа** по списку email или доменам (`vk.ru` → все `@vk.ru`)
- **Пользователи** (email + пароль): регистрация, вход, смена пароля
- Незарегистрированный email из списка доступа → письмо со ссылкой регистрации
- **Забыли пароль?** — сброс через email

## Быстрый старт

```bash
cp .env.example .env
npm install
npm start
```

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `LOGIN_USERNAME` / `LOGIN_PASSWORD` | Админ для загрузки |
| `BASE_URL` | Публичный URL для ссылок |
| `SMTP_*` | Почта (без SMTP письма в консоль) |

## Сценарии

### Загрузка (админ)
1. Войти → перетащить файл
2. **Ссылка**: лимит скачиваний и/или срок (когда перестаёт работать)
3. **Файл**: отдельный лимит скачиваний и/или срок (когда удаляется с сервера)
4. Вкладка «Обновить ссылку» — новые ограничения или замена файла

### Скачивание
- Без ограничений → прямое скачивание
- С ограничениями → форма на `/{имя}`: email/пароль, пароль скачивания
- Email в списке, но не зарегистрирован → письмо с `register.html?token=...`

### Аккаунт
- `/account.html` — вход и смена пароля
- `/user-upload.html` — загрузка файлов (если разрешено админом)
- `/reset-password.html` — «Забыли пароль?»

### Админка (вкладка в панели загрузки)
- Статистика: пользователи, ссылки, файлы, объём, скачивания
- **Лимит диска** — макс. общий объём для обмена (МБ)
- Управление пользователями: галочка «Разрешить загрузку», лимиты (МБ/файл, МБ всего, кол-во файлов, срок)

## Развёртывание на VDS (Ubuntu / VDSina)

### 1. Первичная установка на чистой системе

```bash
# На сервере (Ubuntu 22.04/24.04)
sudo apt-get update && sudo apt-get install -y git
git clone https://github.com/sergey-frolov-pets/share_server.git
cd share_server

# Настройка (домен, пароли)
sudo mkdir -p /etc/share-server
sudo cp scripts/deploy.env.example /etc/share-server/deploy.env
sudo nano /etc/share-server/deploy.env

sudo bash scripts/deploy.sh --config /etc/share-server/deploy.env
```

Скрипт `scripts/deploy.sh` установит Node.js, зависимости, systemd-сервис и nginx.

### 2. Обновление

```bash
sudo bash /opt/share-server/scripts/update.sh
```

Перед обновлением создаётся бэкап `data/share.db` в `/var/backups/share-server/`.

Конфиг развёртывания: `/etc/share-server/deploy.env` (см. `scripts/deploy.env.example`).
