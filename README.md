# Share Server

Минималистичный сервер для обмена файлами по коротким ссылкам.

## Возможности

- Вход по логину и паролю
- Загрузка одного файла через drag-and-drop
- Короткое имя в ссылке: `https://your-domain.com/my-file`
- Лимит скачиваний и срок хранения (автоудаление)
- Проверка уникальности имени

## Быстрый старт

```bash
cp .env.example .env
# Измените LOGIN_USERNAME, LOGIN_PASSWORD, SESSION_SECRET и BASE_URL

npm install
npm start
```

Откройте `http://localhost:3000` — появится окно входа.

## Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `PORT` | Порт сервера | `3000` |
| `SESSION_SECRET` | Секрет сессии | `dev-secret...` |
| `LOGIN_USERNAME` | Логин | `admin` |
| `LOGIN_PASSWORD` | Пароль | `changeme` |
| `BASE_URL` | Публичный URL (для ссылок) | `http://localhost:3000` |
| `MAX_FILE_SIZE_MB` | Макс. размер файла (МБ) | `100` |

## Как это работает

1. Откройте сайт → окно входа
2. Войдите → перетащите один файл
3. Пока файл загружается, введите короткое имя, лимит скачиваний и срок хранения
4. Получите ссылку: `BASE_URL/короткое-имя`
5. Файл удаляется автоматически после истечения срока или при достижении лимита скачиваний

## Структура

```
src/
  server.js    — HTTP API и раздача файлов
  db.js        — SQLite
  auth.js      — авторизация
  cleanup.js   — удаление просроченных файлов
public/        — минимальный UI
uploads/       — файлы (создаётся автоматически)
data/          — база SQLite (создаётся автоматически)
```
